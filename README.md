# GrantWatch Kenya 🌍

**AI-Powered Grant Discovery & Alert System**

A system that automatically finds active grants in Kenya, tracks their deadlines, and sends personalized email alerts to registered users — matched to their sector of interest.

---

## What This System Does

- Finds active grants in Kenya using Manus AI
- Tracks deadlines and hides expired grants automatically
- Sends email alerts 60 days and 30 days before each deadline
- Matches grants to users based on their sector (Agriculture, Tech, NGO, etc.)
- Manages a client database of registered users

---

## Tools Used

- Manus AI — grant discovery and search
- Google Sheets — central database
- Google Apps Script — automation and email alerts
- LLM (Claude / Gemini) — summarization and formatting
- Python — web scraping
- Gmail — email delivery
